# Shrinking Dirichlet layers: supplementary code and data

Supplementary material for **Effective boundary conditions and spectral asymptotics for shrinking exterior Dirichlet layers**, by **Chatchawan Panraksa** ([ORCID](https://orcid.org/0000-0003-0692-5453)).

The repository contains finite weighted-graph checks, interval Galerkin calculations, recorded numerical data, and the graph supplement and Figure 1 with their LaTeX sources. The `manuscript/` directory contains generated table/plot fragments and data only.

## Reproduce the calculations

Use Python 3.12 and NumPy 2.3.5; the recorded reference run used Python 3.12.14. From the repository root:

```sh
python3 -m pip install -r verification/requirements.txt
python3 build.py
```

The build reruns both numerical programs and regenerates the JSON results, table fragments and plot data. No external dataset, network connection, SciPy or plotting library is required for the computations after installing NumPy. Floating-point results can differ at roundoff across platforms.

The graph has eight interior vertices and uses deterministic weights and one random test vector with seed 1729. It uses counting measure and is not a continuum discretization. The interval calculation uses shifted Legendre degrees 8, 16 and 24; fractional orders 0.15, 0.25 and 0.35; and outer quadrature orders 128 and 256. The inner exterior moment rule uses twice the outer order. The finest trial space uses collar widths from 10^-1 to 10^-12.

These finite calculations illustrate the asymptotic formulas. Quadrature and discretization errors are not certified, and the computed values do not certify continuum eigenvalues.

## Supplementary documents

- [Graph supplement](supplements/supplementary_graph_check.pdf) and [LaTeX source](supplements/supplementary_source.zip).
- [Figure 1](supplements/Figure1.pdf) and [LaTeX source and data](supplements/Figure1_source.zip).

Extract each source ZIP into its own directory. With TeX Live, latexmk and PGFPlots installed, compile using:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error -recorder supplement.tex
```

For the figure, use `Figure1.tex` in place of `supplement.tex`. Both archives are flat and include their required local inputs.

[DATA_DICTIONARY.md](DATA_DICTIONARY.md) describes numerical fields and scaling conventions. [FILE_DESCRIPTIONS.md](FILE_DESCRIPTIONS.md) describes the computational files. `SHA256SUMS.txt` records the payload hashes, excluding its own hash. `CITATION.cff` supplies citation metadata for this supplementary material.

OpenAI Codex assisted in developing the Python scripts and PGFPlots source. The numerical values are generated by executing the supplied code, and the curves use the recorded numerical data. Chatchawan Panraksa is responsible for this supplementary material.
